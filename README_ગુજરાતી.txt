APK બનાવવાની રીત (મફત, કોમ્પ્યુટર પર કંઈ install કરવાનું નહીં)
1. github.com પર મફત એકાઉન્ટ બનાવો અને નવી Repository બનાવો (Private રાખો).
2. આ ઝીપ ખોલીને તેની બધી ફાઇલ-ફોલ્ડર (.github સહિત) Repository માં Upload કરો.
3. Actions ટેબ → "Build APK" પૂરું થવા દો (૫-૧૦ મિનિટ) → "Uchchta-APK" ડાઉનલોડ કરો → ઝીપ ખોલતાં app-debug.apk મળશે.
4. APK મોબાઇલમાં install કરો ("અજાણ્યા સ્ત્રોતમાંથી install" ચાલુ કરવું પડશે). પહેલી વાર સ્ટોરેજ પરવાનગી Allow કરો.
ડેટા Documents/Uchchta ફોલ્ડરમાં સેવ થશે.

એપમાં સુધારા (અપડેટ) મોકલવાની રીત – APK ફરી બનાવવાની જરૂર નથી
એક જ વાર:
1. app.netlify.com/drop પર મફત એકાઉન્ટ બનાવી Uchchta_update ઝીપ ખોલેલો ફોલ્ડર ડ્રેગ કરો → તમને લિંક મળશે (દા.ત. https://abc.netlify.app).
2. Code_Generator માં "અપડેટ લિંક" ખાનામાં એ લિંક લખીને જ ખરીદનારનો કોડ બનાવો.
દર સુધારા વખતે:
1. નવો Uchchta_update ઝીપ ખોલી તેનો ફોલ્ડર એ જ Netlify સાઇટમાં (Deploys → ડ્રેગ) મૂકો.
2. ખરીદનાર ઇન્ટરનેટ સાથે એપ ખોલે એટલે "નવી આવૃત્તિ મળી – અપડેટ કરો" દેખાશે. ડેટા, લોગીન, એક્ટિવેશન એમ જ રહેશે.

નોંધ: debug.keystore ફાઇલ કદી ડિલીટ/બદલશો નહીં (ફક્ત APK ફરી બનાવવો પડે ત્યારે જરૂરી).
